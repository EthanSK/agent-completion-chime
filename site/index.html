A chime when an agent finishes. A different chime when they're all done.

You walk away while six subagents grind. You hear a Glass: one of them wrapped up. You hear another, and another. Eventually a Hero: come back to the desk.

agent-completion-chime hooks into Claude Code's Stop & SubagentStop, OpenClaw's subagent runtime, or any CLI you can call on exit. Two configurable macOS chimes. No menubar, no Electron, no Swift.

01

Install

# one-shot install (Claude Code + OpenClaw + watcher LaunchAgent)
git clone https://github.com/EthanSK/agent-completion-chime
bash agent-completion-chime/scripts/install.sh

# or, just the binaries (no harness wiring)
npm install -g agent-completion-chime
chime test per-agent
chime test all-complete
  • One-shot installer wires Claude Code Stop+SubagentStop hooks, registers as a directory-source plugin, and installs an OpenClaw watcher LaunchAgent. Idempotent. --dry-run and --uninstall supported.
  • Pure Node + afplay. No Electron, no Swift.
  • State in ~/.agent-completion-chime/.
  • 14 built-in macOS sounds, or any .aiff/.wav/.mp3.
  • Two binaries: chime (CLI for hooks) + agent-completion-chime-mcp (configure via talking to an agent).
  • Verify wiring with node bin/chime.js install-status — Y/N truth-table.
02

Hook it up

Claude Code

// ~/.claude/settings.json
{
  "hooks": {
    "Stop": [{ "matcher": "", "hooks": [{
      "type": "command",
      "command": "chime end --from-claude-hook --quiet"
    }]}],
    "SubagentStop": [{ "matcher": "", "hooks": [{
      "type": "command",
      "command": "chime end --from-claude-subagent --quiet"
    }]}]
  }
}

OpenClaw

# Background watcher — translates ~/.openclaw/subagents/runs.json transitions.
nohup node $(npm root -g)/agent-completion-chime/scripts/openclaw-watcher.js \
  > /tmp/chime-openclaw.log 2>&1 &

Anything else

chime start "ci-build-$BUILD_ID" --source github-actions
# ... your work ...
chime end   "ci-build-$BUILD_ID" --source github-actions

04

Configure by talking

Add the MCP server to Claude Code (or any MCP host). Then change the chimes mid-flight.

// settings.json
{
  "mcpServers": {
    "agent-completion-chime": { "command": "agent-completion-chime-mcp" }
  }
}

"Set the per-agent chime to Pop and the all-complete chime to Submarine. Disable for an hour."
